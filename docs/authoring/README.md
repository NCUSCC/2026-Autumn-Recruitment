# 题目编写指南

题目内容由独立节点和地图组成。节点描述一个可执行、可校验的能力单元；地图只描述节点之间的编排、分流和汇合。

## 节点最小信息

- 稳定的节点 ID 和版本。
- 面向参与者的任务说明和分层提示。
- 可观察、可自动判断的通关条件。
- 所需 profile/Sandbox 引用、资源上限和离线输入。
- CheckerResult 的公开反馈和组织者反馈边界。

首版题目应适合零基础新生，先验证一个小闭环，再通过可选节点增加深度。不要把最终答案、隐藏测试或个人信息放进公开节点包。

## 地图原则

地图负责拓扑，不负责实现题目逻辑。节点可以被多个地图复用，边的触发条件应结构化且可解释。详细 schema 和编辑器使用方式见 `docs/design/map-editor-design.md`。
