# NCUSCC 考核内容

本目录保存可以被平台加载、校验和编排的公开考核内容。

## 目录

- `catalogs/`：阶段、方向、标签和 profile 索引。
- `maps/`：地图文档，描述节点和边的编排关系。
- `nodes/`：独立节点包，后续可包含说明、提示、通关条件和资源引用。
- `checkers/`：公开 checker 配置或可公开的示例实现。

真实招新活动中的隐藏测试、参考答案、个人信息和凭据不得提交到公开仓库。需要保密的内容应放在受控的私有内容包中，并在发布时锁定与公开地图相同的版本。

内容必须使用仓库中声明的 schema 版本，并能够在断网环境下完成结构校验。
